# raizativa-midia

Vídeos e imagens dos posts da RaizAtiva nas redes ([@raizativaagro](https://instagram.com/raizativaagro)).

Este repositório é público só para que o agendador de posts (Metricool) consiga baixar os arquivos por um link aberto. O código do site fica em outro repositório, privado.

Organização: `reels/<data do post>-<tema>/` com `video.mp4` e `capa.jpg`.
